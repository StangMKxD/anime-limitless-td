# ลำดับการอ่านเอกสารและแผนงาน (Documentation Reading Order)

ก่อนเริ่มงานในโปรเจกต์ Anime Limitless Tower Defense ควรอ่านเอกสารตามลำดับดังต่อไปนี้:

1. **[`AGENTS.md`](../AGENTS.md)** — กติกาหลักของโปรเจกต์ การแบ่งหน้าที่ SoD และ Canonical Rules (R01–R08)
2. **[`docs/READ.md`](READ.md)** — แผนผังและลำดับการอ่านเอกสาร (เอกสารนี้)
3. **[`docs/CONTEXT.md`](CONTEXT.md)** — บริบทของเกม คำศัพท์ และ Invariants สำคัญ
4. **[`docs/CONVENTIONS.md`](CONVENTIONS.md)** — กติกา Git Worktree, การแบ่งพอร์ต Rojo และ Coding Standards
5. **[`TASKS.md`](../TASKS.md)** — บอร์ดแสดงสถานะรวมของแต่ละ Plan
6. **[`docs/requirements/PRD.md`](requirements/PRD.md)** — ข้อกำหนดเชิงฟังก์ชันของระบบเกม
7. **[`docs/technical/TDD.md`](technical/TDD.md)** — การออกแบบสถาปัตยกรรมระบบโดยละเอียด
8. **[`docs/technical/API.md`](technical/API.md)** — สัญญาข้อมูล Attributes, Remotes และ Constant Keys
9. **[`src/Shared/GameConfig.luau`](../src/Shared/GameConfig.luau)** — ไฟล์ Data Contract กลางของโค้ด
10. **[`docs/implementation-plans/README.md`](implementation-plans/README.md)** — ดัชนีแผนงานและเอกสารเจาะจงราย Track:
    - [PLAN-0001: Track 1 Core Wave System](implementation-plans/0001-core-wave-and-enemy-scaling/PLAN.md)

    - [PLAN-0003: Track 3 Infinite Upgrade UI & Server](implementation-plans/0003-infinite-upgrade-and-ui/PLAN.md)
